## 🫘 Peanut Analysis – Producción de Maní (1927–2024)

Proyecto de análisis histórico de la producción de maní en Argentina, utilizando Excel avanzado, funciones dinámicas y tablas dinámicas para exploración, validación y visualización de datos.

---

### 📁 Dataset

- Fuente: mani-serie-1927-2024.csv

- Información por:

    - provincia
    
    - departamento
    
    - campaña
    
    - superficie sembrada y cosechada
    
    - producción (tm)
    
    - rendimiento (kg/ha)

---

## 🧠 Herramientas y técnicas utilizadas
🔹 Excel (Microsoft 365)

- Funciones dinámicas:

    - FILTRAR, ORDENAR, UNICOS
    
    - TOMAR, APILARH, ELEGIRCOLS
    
    - TRANSPONER

- Agregaciones condicionales:

    - SUMA, PROMEDIO, SUMAR.SI.CONJUNTO

- Análisis sin VBA:

    - Rankings dinámicos
    
    - Extracción de registros asociados a máximos

- Tablas dinámicas para:

    - Resúmenes por provincia
    
    - Análisis histórico
    
    - Comparaciones por campaña

- Validación de datos:

    - Listas desplegables
    
    - Control de filtros
    
    - Gráficos embebidos para reporting
